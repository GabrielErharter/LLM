## Conceitos Fundamentais

**Inteligência Artificial (IA)**
Área da computação que busca criar sistemas capazes de realizar tarefas que normalmente exigem inteligência humana.

**Machine Learning (ML)**
Subárea da IA em que sistemas aprendem padrões a partir de dados, sem serem programados diretamente para cada situação.

**Deep Learning (DL)**
Subárea do ML que utiliza redes neurais com várias camadas para aprender padrões complexos em grandes quantidades de dados.

**Large Language Model (LLM)**
Modelo treinado com grandes quantidades de texto para compreender e gerar linguagem.

## Arquitetura e Modelos

**Transformer**
Arquitetura de redes neurais que utiliza atenção para analisar relações entre diferentes partes de uma sequência.

**GPT (Generative Pre-trained Transformer)**
Família de modelos baseada em Transformers, pré-treinada com grandes quantidades de texto para gerar conteúdo.

**Atenção (Attention) / Self-Attention**
Mecanismo que permite ao modelo identificar quais partes do texto são mais importantes para entender o contexto.

**Embedding**
Representação numérica de tokens que permite ao modelo trabalhar com seus significados e relações.
**Tokenização (Tokenization)**
Processo de dividir o texto em unidades menores chamadas tokens.

## Treinamento

**Pré-treinamento (Pretraining)**
Etapa em que o modelo aprende padrões gerais da linguagem usando grandes quantidades de texto.

**Fine-tuning**
Etapa em que um modelo pré-treinado é ajustado para tarefas ou comportamentos específicos.

**Corpus de treinamento**
Conjunto de dados, principalmente textos, utilizado para treinar o modelo.

## Fluxo Geral

**Fluxo de funcionamento de um modelo de linguagem**
Entrada → Tokenização → Embedding → Processamento pelo Transformer → Saída

O texto é dividido em tokens, transformado em representações numéricas, processado pelo modelo para analisar o contexto e, por fim, o modelo gera a resposta token por token.
